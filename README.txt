UP Scholarship Status — GitHub Pages package
=============================================

Domain: https://upscholarshipstatus.co.in

IMPORTANT: This ZIP is ready to upload with GitHub Desktop. The ZIP itself is not uploaded as a website. Extract it first.

EASIEST UPLOAD METHOD (GitHub Desktop):
1. Install GitHub Desktop: https://desktop.github.com/
2. On GitHub website, create a repository named upscholarshipstatus.
3. In GitHub Desktop, choose File > Clone repository and clone that repository to your computer.
4. Extract this ZIP. Copy ALL contents from the extracted folder (including assets, page folders, CNAME and .nojekyll) into the cloned repository folder.
5. If asked, replace files. Ensure index.html is directly at the repository root, not inside an extra folder.
6. In GitHub Desktop, write a summary such as “Add static website template”, click Commit to main, then click Push origin.
7. On GitHub website, open repository Settings > Pages. Select Deploy from a branch, branch main, folder /(root), then Save.
8. Custom domain is prefilled via CNAME. In the domain provider DNS settings, add the DNS records GitHub Pages shows for this domain. HTTPS can be enabled after DNS verifies.
